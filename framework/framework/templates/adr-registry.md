## Statuses

- **Draft** — Under discussion
- **Accepted** — Decision approved and in effect
- **Superseded** — Replaced by a newer ADR (link in last column)
- **Deprecated** — No longer relevant

## How to add an ADR

1. Copy `framework/templates/adr.md` to `work-item/[slug]/03-design/adr-NNN-short-title.md`
2. Add a row to this registry
3. Link the ADR file in the row title
